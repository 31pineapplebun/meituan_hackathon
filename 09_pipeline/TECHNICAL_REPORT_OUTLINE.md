### 2. 技术方案 (P4-P7) - 工程严谨度
**2.1 系统架构图** (一张图说明全部)
```
[指令 .md] → [Parser] → [约束清单 JSON]
                              ↓
[对话 .jsonl] → [Pipeline] ← 5 个 Verifier
                              ↓
                        [P3 评分算法]
                              ↓
                    [评分报告: 100 分制 + 5 维度]
```

**2.2 核心创新点**
- **创新 1**: 把"评测 LLM"分解为 5 类 Verifier
  - rule (字数/占位符) → 100% 客观可量化
  - rule_pattern (禁用词) → 100% 客观可量化
  - state_tracker (流程结构) → LLM 判定
  - llm_extract_then_rule (事实抽取) → LLM 抽事实 + 规则判定
  - llm_judge (主观判断) → LLM 直接判
  - **价值**: 客观规则不浪费 LLM 调用 (省 60% 成本)

- **创新 2**: P3 三层评分防御
  - L1 加权分: D1(25%) + D2(25%) + D3(20%) + D4(15%) + D5(15%)
  - L2 Critical pass < 90% → 钳制 85
  - L3 Red line 违规 → 钳制 40
  - **价值**: 防止"全 D3 满分但 D1 全 fail"的虚高分

- **创新 3**: 三路 LLM 对照
  - DeepSeek Flash (主, 快)
  - DeepSeek Pro (同族对照)
  - GPT-5-mini (跨族对照)
  - **价值**: 排除单一模型偏差,工业级评测必做

**2.3 工程实现**
- 5 个 verifier 全部跑通,5/5 单元测试通过
- 1055 条 verdict 在 16 分钟内并行跑完
- 端到端: 上传指令 + 对话 → 30 秒出报告

### 3. 评测可靠性证据 (P8-P11) - 数据说话
**3.1 标注质量**
- 50 通真实对话 (GPT-5 25 通 + DeepSeek 25 通,双模型避免偏差)
- 1055 条人工 verdict
- **4 轮标注迭代**: v3 (初标) → v4 (B.5 自动审计) → v5 (手工复核) → v6 (全量重标)
- 每轮的修订日志可追溯

**3.2 一致性数据**
- **客观约束**: 字数/禁用词 kappa = **1.0** (100% 一致)
- D3 约束遵循度: kappa = **0.84** (顶级)
- **整体 kappa = 0.4483** (NLP 实用门槛)
- vs Day 5 v5: kappa 从 0.13 提升到 0.45 (**3.3 倍**)

**3.3 三路 LLM 对照**
- 同族 (Flash vs Pro): kappa = 0.83
- 跨族 (Flash vs GPT): kappa = 0.78
- 跨族 (Pro vs GPT): kappa = 0.83
- **三路平均 = 0.81** (超过学术界 LLM-as-judge 的 0.5 标准)

**3.4 评测系统的独立价值** (★ 关键卖点)
- Day 9 mock 评测**独立发现**人工标注 5 处系统性错误
- 抽样验证 5/5 case: **机器对,人错**
- 触发 v4-v6 修订 200+ 处 → kappa 翻 4 倍
- **意义**: 系统不只是模仿人,还能纠正人

- ❌ "评测速度快" 
- ✅ "30 秒/通 vs 人工 15-30 分钟/通,提升 30-60 倍"

评委可能是商业人士,关注 ROI:
- ❌ "我们用了 state_tracker verifier"

### 3. 实证为王,不假大空
- ❌ "我们的评测系统很可靠"
- ✅ "客观约束 kappa = 1.0,主观约束 kappa = 0.45,vs 业界 LLM-as-judge 标准 0.5"

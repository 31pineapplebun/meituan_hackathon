# 优化建议 (3 条)

## 🔴 严重问题 (1 条)

### 1. [V4_C20] 流程结构: S6 取消订单流程：引导商家在商家版 APP 操作取消订单。

**问题**: S6 缺失或不完整: 取消订单流程：引导商家在商家版 APP 操作取消订单。

**根因**: 助手未按指令规定的流程顺序执行,跳过了关键步骤

**改进**: 在对话中明确执行 S6,不要省略

**改后示例**:
```
话术: '麻烦您在商家版 APP > 订单管理 > 找到该单 > 点击取消'
```

**预期效果**: 流程完整度提升,D1 维度分提升

## 🟡 重要问题 (2 条)

### 1. [V4_C01] 字数限制: 每次回复控制在 15-20 字左右，保持精简。

**问题**: 3 处超 25 字 (最严重: T7 = 45 字)

**根因**: 助手在单轮塞入过多信息,缺乏'一轮一焦点'意识

**改进**: 将长 turn 拆成 2-3 个连续短 turn,每轮聚焦 1 个信息点

**改后示例**:
```
原 T7 (45字) → 拆成:
  • T7: '谢谢您的配合，我会帮您转达给骑手和用户，让他们等一下。' (27字)
  • T9: '请您再加油！还有其他需要我帮忙的吗？' (18字)
```

**预期效果**: 字数违规率从当前 → 0%

---

### 2. [V4_C07] 禁用词: 对话中绝对不说“好的”、“哈哈”等不专业的词。

**问题**: 使用了约束禁用的语气词: turn9用了'好的'

**根因**: 助手用了不专业的语气词,违反指令规范

**改进**: 替换为: 用 '行/明白/收到/嗯'

**改后示例**:
```
将 '好的' 换成 '行' 或 '收到'
```

**预期效果**: 禁用词违规消除

# 标注速查表（一页打印贴屏幕旁）

## 4 步流程（每条约束必走）

```
① 读 name → 这条要判什么?
② 看 verifier 类型 → 用哪类标准?
③ 条件约束: 先判触发  (没触发就 na, 不是 pass!)
④ 应用标准 + 写 evidence (能直接证明 verdict!)
```

## 4 类心智红线

| ❌ 错误心智 | ✅ 正确心智 |
|---|---|
| "对话挺好的 → pass" | "这条约束说 X → 有/没有 X → pass/fail" |
| "Evidence 描述对话" | "Evidence 证明 verdict" |
| "约束没违反就 pass" | "没触发就 na" |
| "整体印象判" | "每条独立判" |

## verdict 状态边界

| 状态 | 何时用 |
|---|---|
| pass | 约束适用 + 满足 |
| fail | 约束适用 + 违反 |
| **na** | **条件未触发**（最常错） |
| review | 真不确定（不要硬猜! 标 review 是诚实） |

## 按类型判定 cheat sheet

### rule (字数)
- 数每轮 assistant 字数，首轮豁免
- 上限 + 5 = 软边界，超即违规
- 违规率 ≥ 30% → fail

### rule_pattern (禁用词)
- 全文搜禁用词，含变体（"好的呀"算）
- 出现 1 次 → fail

### state_tracker (流程)
- 只看意思到没到，**不看字数、不看格式**
- 字数违规归 rule，不归这里！

### llm_judge "口语化"
- 列点 → fail
- 书面词≥2 → fail
- 完全没口语词 → fail
- 都不满足 → pass

### llm_judge "适时结束"
- 用户明确说结束后,助手追问 ≥ 2 轮 → fail
- 强制截断没自然结束 → fail

### llm_judge "条件应答" (若X则Y)
- X 没触发 → **na**!
- X 触发 + Y 做了 → pass
- X 触发 + Y 没做 → fail

### llm_extract "禁止承诺"
- 找助手是否说出"折扣/补贴/赔付/补偿/优惠/免单/返现"
- 配合"我帮您/我会/保证/肯定" → fail
- 全文都没提 → pass

### llm_extract "越界处理"
- 用户没问越界 → na
- 用户问越界 + 助手用"我向同事确认/记录后回复" → pass
- 用户问越界 + 助手直接答 → fail

## 高频陷阱

| 陷阱 | 警惕信号 |
|---|---|
| 字数违规归到 S1 流程 | evidence 含"超长 T7=45字" 但约束不是字数 |
| 条件没触发标 pass | "若X则Y" 约束我标 pass 但 X 没发生 |
| 适时结束标 pass | 看到最后挂电话就标 pass，没数追问轮数 |
| Evidence 错位 | 写完 evidence 念一遍，能证明 verdict 吗? |

## 疲劳检测信号

- ❌ 开始凭整体印象（不再回看具体约束）
- ❌ Evidence 越写越短或抄上一通
- ❌ 心里想"差不多就 pass 吧"
- ❌ 一通对话 90% pass / 0% fail

**任一信号出现 → 立即休息 5-10 分钟**

## 节奏建议

- 每标 5 通休息 5 分钟
- 每天最多标 15-20 通（不要熬夜）
- 50 通分 3-5 天做完
- 不确定就 review，绝对不硬猜

---

**两条最重要原则**:

1. **每条约束独立判, 不用整体印象**
2. **Evidence 必须能直接证明 verdict**

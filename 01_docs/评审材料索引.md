## 3. 如何运行（现场演示）

```bash
cd 10_streamlit_app
streamlit run app.py
```

- **⚡ 快速演示**（推荐录制/演示）：读预生成的真实评测结果，秒出，无需 API key。
- **🔬 完整运行**：真调模型，需 `DEEPSEEK_API_KEY`（或 `OPENAI_API_KEY`）。
- **三种输入**：① 选预置指令→评模型；② 自定义【完整任务指令】→解析→多场景模拟→评模型；③ 给一通对话 / 给一句大致描述→单通质检。

## 6. 诚实声明（已主动纠正/披露）

- 早期口号「省 ~60% LLM 成本」**经核实站不住**（两官方样本主观约束占大头、必须用 LLM，真实可省约 4 成约束、估算），已在报告/关于页/README 改为诚实表述。
- 整体 Kappa 0.45 受「Kappa 悖论」（类别不平衡）系统性低估，故**同时报告一致率 81.8%**，并按维度/类型拆解；不刷高 κ。
- 主观约束（口语化/流程到位）与人工 κ 为中等，是所有 LLM-as-judge 系统的共同课题。
- 市场规模为量级估算，非精确市场报告数字。

# 演示视频脚本 — 对话外呼指令遵循自动评测系统

> **目标时长**：约 **3.5–4 分钟**（初赛演示）
> **录制建议**：① 用 **⚡ 快速演示** 模式录主流程（读预生成的真实结果，秒出、稳定、不依赖 API）；② 真实分数以仓库实测为准（飞毛腿 63.6 / 课程发布 44.2）；③ 全程 1080p、浅色主题、字号已调大。
> **格式**：每段含 `[时长]`、**旁白**（念稿）、【画面】（操作/镜头）、字幕要点。

---

## 0. 痛点开场 `[0:00–0:25]`

**旁白**：
> "美团正在用 AI 数字人给骑手、商家打电话——提醒出勤、通知政策、自动招聘。可是一个问题来了：**AI 外呼能无限扩，谁来检查它说得对不对?** 每通电话都挂着复杂的任务指令——多步流程、字数限制、不能乱承诺。靠人工质检，一通要十几二十分钟，**根本审不过来**。"

【画面】：标题页 → 一张"AI 外呼数量↑ / 人工质检产能持平"的对比示意（或两个官方指令 markdown 快速滚动，体现"约束很多很复杂"）。

字幕：**人工质检：慢、贵、不一致、难量化、难给方向**

## 1. 定位 `[0:25–0:42]`

**旁白**：
> "我们做的，就是把这件事自动化：**输入一个任务指令、选一个待测模型，系统自动模拟多种用户场景跟它对话，再逐条约束打分，产出 0 到 100 分、可解释、能指出怎么改的模型能力画像。**"

【画面】：打开 Streamlit 首页，镜头扫过左侧专业看板（核心能力 / Kappa 指标）+ 顶部能力数字条（23 类约束 / 5 类 Verifier / 8 Persona / κ0.81）。

字幕：**输入指令 + 模型 → 自动模拟·评测 → 可解释能力画像**

## 2. 主流程现场演示（评模型）`[0:42–2:05]`

**旁白**：
> "第一步，选任务指令。我们直接用官方样本——飞毛腿骑手合同通知。系统**自动把这份指令拆成了 15 条原子约束**：字数、流程、禁用词、FAQ 知识，每条都标了用哪种判定器、属于哪个评分维度。"

【画面】：第 1 步选「🏢 官方 Sample 1 - 飞毛腿合同」→ 展开「约束清单」表格 + verifier 分布饼图。

**旁白**：
> "第二步，一键运行。系统用多种用户画像——配合、坚持拒绝、越界提问、打断等——分别跟模型对话，覆盖指令里的各种情况，再逐条约束判定。"

> （注：快速演示展示这 4 个核心场景的真实数据；完整运行模式可跑全部 8 种用户画像。）

【画面】：第 2 步保持默认 → 选 **⚡ 快速演示** → 点「🚀 运行评测」→ 进度条/秒出。

**旁白**：
> "几秒钟，模型能力画像出来了：**综合 63.6 分，需改进**。五维雷达一眼看出强弱——任务完成满分，但知识维度是 0；各场景里'坚持拒绝型'最弱只有 45 分。再往下，**最常违反的约束**直接点名：字数控制失败率 100%、FAQ 知识没覆盖。"

【画面】：模型画像卡（63.6）→ 雷达图 → 各场景条形（最弱在前）→ 最弱约束表。

**旁白**：
> "最关键的是**可解释**——点进单通详查，每一条判定都能看到证据：是哪一轮、说了什么、为什么判 fail。这不是一个黑盒分数，是能直接拿去改模型的诊断书。"

【画面】：点「📂 查看某一通对话的细节」→ 单通详查页：左侧对话逐轮、右侧逐约束判定（pass/fail + 证据高亮）。

字幕：**0–100 分 + 5 维画像 + 最弱约束 + turn 级证据**

## 3. 灵活的输入方式 `[2:05–2:45]`

**旁白**：
> "除了官方指令，**你也可以输入自己的任务指令**——粘进来，系统现场解析、模拟、评测，完全一样的流程。如果你手上已经有一通真实对话，也可以直接粘进来评质量；甚至只给一句话'生成一段易怒用户和数字人的对话'，系统会先模拟出对话再评。"

【画面】：第 1 步切「✍️ 自定义输入」→ 快速展示三个子选项（📋 完整任务指令 / 💬 直接给对话 / ✏️ 大致描述）→ 在「✏️ 大致描述」里输入示例 → 模拟出对话 + 评测结果一闪而过。

字幕：**预置 / 自定义指令 / 已有对话 / 一句话生成 —— 都能评**

---

## 4. 凭什么相信它准？`[2:45–3:25]`

**旁白**：
> "评测器自己准不准，用数据说话。客观约束——字数、禁用词——跟人工标注 100% 一致，Kappa 等于 1。整体 Kappa 0.45、实际一致率 81.8%，这是 LLM 评测和人工对比的健康区间，高于这个反而要警惕。我们还用三个不同模型族交叉验证，互相一致度 0.81，排除单一模型偏差。"

【画面】：切到「📖 关于」页 → Kappa 指标卡（客观 1.0 / 整体 0.45 / D3 0.84 / 三路 0.81）+ 工程可靠性表。

**旁白**：
> "更有意思的是：在标注迭代中，**评测系统反过来发现了人工标注的系统性错误**——抽样验证，多数是机器对、人错。它不只是模仿人，还能纠正人。"

字幕：**客观 κ=1.0 · 整体 κ=0.45 + 一致率 81.8% · 三路互查 0.81**

## 5. 价值收尾 `[3:25–3:55]`

**旁白**：

【画面】：回到模型画像页定格 → 叠加三个数字：**~¥0.2/通 · 数十秒 · 全量可复现** → 收尾标题页。
